# 책빌리지 (Book Village) — 작은도서관 도서 대여 관리 프로그램

> ## 🎉 책빌리지 1호점이 문을 열었습니다!
>
> 아파트 단지 안 작은도서관 **1호점**이 실제로 책빌리지로 운영을 시작했습니다.
> 도서 등록부터 주민 셀프 대여, 독서 퀴즈·독서록·젤리 포인트까지 — 스마트폰 하나로 무인 운영되고 있는 생생한 현장 이야기를 확인해 보세요.

### ✦ 우리 도서관에 꼭 맞게 — AI와 함께 고쳐 쓰는 책빌리지

책빌리지는 **아파트 · 학교 · 마을 · 유치원 · 학원** 등 여러 운영 방식을 하나의 코드로 지원합니다. 그만큼 모든 도서관의 방식을 처음부터 그대로 담아낼 수는 없습니다.

그래서 처음부터 **고쳐 쓰기 좋은 구조**로 설계했습니다.

- 화면, 서버 기능, 데이터베이스가 역할별로 깔끔하게 나뉘어 있습니다
- 운영 방식(모드)마다 기능을 켜고 끄는 기준이 한곳에 모여 있어, 한 모드를 고쳐도 다른 모드에 번지지 않습니다
- 데이터베이스 변경 이력이 번호 순서대로 남아 있어 어떤 사이트에도 같은 구조를 재현할 수 있습니다

이 구조 덕분에 **Claude Code**나 **Codex** 같은 AI 코딩 도구에 *"우리 도서관은 반마다 대출 기간을 다르게 하고 싶어요"* 처럼 평소 말로 요청하면, AI가 코드를 읽고 알맞은 곳을 정확히 고쳐 줍니다. AI가 가장 먼저 읽도록 구조와 규칙을 정리한 안내서 [`AGENTS.md`](AGENTS.md)도 함께 들어 있습니다.

**월 2~3만 원대 AI 구독**(Claude Pro, ChatGPT Plus 등)이면 충분합니다. 기본 기능으로 먼저 운영해 보시고, 우리 도서관만의 방식이 필요해지면 AI와 함께 한층 더 완성도 있게 다듬어 보세요.

- **AR 퀴즈 통과 기록 · AR 포인트 랭킹** ([화면 보기](#academy-return)) — 반납 화면·반별 현황·학생 상세에서 선생님이 통과를 체크하면 포인트·단어 수가 쌓임(젤리와는 별개). 랭킹에 AR 포인트 탭(반 필터, 한국 시간 기준), 학생 내 서재에 AR 독서 카드·'내 레벨 책'
- **레벨 라벨 인쇄** ([화면 보기](#academy-labels)) — 책등에 붙이는 AR 레벨 라벨(23.5×36mm, A4 한 장에 56개), 레벨대별 색 띠
- **사이트 유형 판별 정리** — 모드 판별을 `src/lib/site-mode.ts` 한 곳으로 모음. 모르는 유형 값이 저장돼 있어도 로그인 화면이 멈추지 않게 수정, 사이트 유형·프리셋 저장 실패 시 오류 표시
- **AI로 고쳐 쓰기 안내 · `AGENTS.md`** — README 상단 안내와 AI 코딩 도구가 먼저 읽는 구조·규칙 안내서 추가

- **로그인·대출 방식 설정** ([화면 보기](#kids-access)) — 로그인 방식(휴대폰/QR 카드), 회원 가입(본인 가입/관리자만), 홈 화면 리더기 대출과 자동 로그아웃 시간을 지점별로 설정. 유치원 선택 시 한 번에 적용

- **도서 분류** — 연령(0~3세·4~7세·초등 1~2/3~4/5~6학년·청소년·일반), 유아 하위 분류(놀이·그림책·교양·학습·캐릭터), 전집(시리즈) 이름, 교과연계 학년. 분류별·책장별 보기, 옮겨야 할 책 강조, 전집 이름 일괄 변경(오타로 갈라진 전집 합치기), 분류 목록 인쇄. 알라딘·교보 정보로 일괄 분류하는 스크립트(`scripts/classification`)
- **책장 이동** — 옮길 책장을 고르고 바코드(리더기·카메라)를 찍으면 바로 이동, 되돌리기 지원. 재배치안 자리와 다르면 경고
- **자료실** — 인쇄용 파일(pdf·한글·워드·엑셀 등)을 올려두고 도서관 PC에서 원래 파일 이름으로 내려받기
- **월별 신간 인쇄 — 목록형** — 분류·제목 표 + 양옆 표지 기둥. 표지 수·표지 크기·글자 크기 조절, A4 한 장 자동 맞춤. 기존 표지형도 선택 가능
- **비회원 대출 개편** — 동/호수만 입력하면 이전에 빌려 간 분이 바로 후보로 떠서 한 번에 선택(회원/비회원 표시, 대출 횟수). 누구 → 연락처 → 책 → 확인 단계로 진행, 제목 검색과 바코드 스캔을 한 칸에서, 책 상세 보기, 휴대폰에서도 큰 글씨·큰 버튼
- **기타** — 지점별 홈 화면 앱 이름(`NEXT_PUBLIC_APP_NAME`), 관리자 메뉴 스크롤, 1,000권이 넘어도 서재별 도서 수 정확히 표시, 새 지점 설정 저장·셀프 대출 권한 수정

### v0.6

- **월별 신간도서** — 관리자가 매월 신간을 등록해 주민에게 공개. 교보/온라인 서점 링크만 붙여넣으면 제목·표지 자동 추출(직접 입력도 지원), **연령별 분류**(유아·어린이·청소년·성인), 순서 조정·수정·삭제
- **신간도서 A4 인쇄** — 게시용 인쇄 미리보기. 한 장에 자동 맞춤(내용량에 따라 자동 축소), 한 줄 권수·크기 수동 조절, 제목은 고정 크기 유지, 도서관 이름 자동 표기. 분류(유아·어린이·청소년·성인)는 섹션으로 나누지 않고 순서대로 쭉 나열하되 **색상으로만 구분**(번호 배지·표지 테두리·상단 색 범례)
- **구매 영수증 관리** — 월별 도서 구매 영수증 **이미지·PDF 업로드**(여러 장, PDF는 페이지별로 한 장씩 자동 저장)·메모·순서 조정·삭제, 정산/보고용 인쇄
- **독서록 전용 에디터** — 반납 도서 독서록을 풀스크린 전용 화면에서 작성. 큰 별점 버튼, 작성 가이드 힌트(탭하면 질문이 입력창에 삽입), 하단 고정 등록 버튼으로 편하게 작성
- **내 독서록 모아보기** — 내 서재에 '내 독서록' 메뉴 추가. 내가 쓴 독서록을 별점·감상문·작성일과 함께 모아 보기(작성 편수 배지)
- **퀴즈 없는 책은 퀴즈 버튼 숨김** — 등록된 퀴즈가 없는 도서는 반납완료 목록에서 퀴즈 버튼을 아예 표시하지 않음

### v0.5

- **공지사항** — 관리자 공지 작성/이미지 첨부/관리, 주민 접속 시 팝업 노출 + 내 서재·하단 네비 미읽음 배지 + 목록 열람
- **주민 대여 취소** — 대여 당일에 한해 주민이 직접 취소 (지급된 대출 젤리 자동 회수)

- **도서 정보 수정** — 관리자 도서 상세에서 제목·저자·출판사·서가 위치·표지 직접 수정
- **실제 ISBN 직접 입력 등록** — 카카오 검색이 안 되는 도서를 ISBN 직접 입력으로 등록(중복 자동 검사)
- **바코드 스캔 한글 IME 복원** — 리더기가 한글 입력 상태로 `BV`를 `ㅠㅍ`처럼 찍는 문제 자동 복원
- **가나다순 자연 정렬** — 도서 목록 제목순 정렬 시 `전천당 1, 2, …, 10` 순서 유지
- **자체 바코드 대량 인쇄** — 한 번에 최대 1,000장 생성·인쇄
- **로고 인쇄** — 도서관 로고 스티커 인쇄 페이지
- **홈 화면 추가(PWA)** — manifest·앱 아이콘 적용으로 스마트폰 홈 화면에 앱처럼 설치
- **대시보드 카드 클릭 이동** — 통계 카드 클릭 시 해당 목록으로 바로 이동
- **도서 상세 서가 미니맵** — 위치 서가를 확대·강조(펄스 애니메이션)해 찾기 쉽게 표시
- **검색 상태 유지** — 도서 검색 후 뒤로가기 시 검색어·결과 보존
- **무인 도서관 이용 안내문** — 인쇄용 A4 가이드(앱 안내 / 수기 대여 / 최대 5권 등)

## 소개 
> 관리비 0원으로 운영하는 작은도서관 도서 대출/반납 관리 시스템

아파트, 학교, 마을 작은도서관을 위한 **무료 오픈소스 도서관 관리 프로그램**입니다. 바코드 스캔으로 도서 대여/반납, 도서 검색, 연체 관리, 독서 퀴즈, 독서록까지 — 스마트폰 하나로 도서관을 운영할 수 있습니다.


## 왜 만들었나요?

> *"관리할 사람이 없어서 닫히는 도서관이 하나라도 줄었으면 합니다."*

아이를 키우면서 동네 작은도서관을 자주 찾습니다. 그런데 사람이 없어 문을 닫거나, 운영을 포기하는 곳이 점점 늘어나고 있었습니다.

수기 장부, 엑셀 대장, 수작업 연체 관리... **아날로그 방식의 도서관 운영은 자원봉사자에게 너무 큰 부담**입니다. 결국 지치고, 포기하게 됩니다.

하지만 **아이들에게 도서관은 특별한 공간**입니다. 책을 직접 만지고, 고르고, 읽는 경험은 어떤 디지털 콘텐츠로도 대체할 수 없습니다. 이 공간이 사라지는 건 너무 아까운 일이었습니다.

그래서 직접 만들었습니다.

- **스마트폰 하나면 충분합니다** — 누구나 사서가 될 수 있고, 주민은 셀프 대여까지 가능합니다
- **관리비 0원** — Vercel + Supabase 무료 플랜으로 운영비가 들지 않습니다
- **아이들이 즐거워합니다** — 독서 퀴즈를 풀고, 독서록을 쓰고, 젤리 포인트를 모으며 "오늘 젤리 몇 개 모았어!" 하고 좋아합니다

### 5. 리더기 대출·반납 (키오스크)

도서관 태블릿이나 PC에 2D 바코드 리더기를 연결해 두면 홈 화면이 **"회원카드를 찍어주세요"** 대기 화면이 됩니다.

1. 아이가 회원카드를 찍으면 이름으로 인사하고
2. 빌릴 책의 바코드를 찍으면 바로 대출됩니다. 여러 권을 이어서 찍을 수 있어요.
3. **다 빌렸어요**를 누르거나 정해 둔 시간 동안 입력이 없으면 자동으로 끝나고 대기 화면으로 돌아갑니다.

반납할 책은 카드 없이 대기 화면에서 책 바코드만 찍으면 됩니다. 리더기가 한글 입력 상태여도 자동으로 고쳐서 읽습니다.

### 필요한 것

- **2D(QR) 바코드 리더기** — QR 회원카드를 읽어야 해서 1D 전용 리더기는 안 됩니다. USB로 꽂으면 키보드처럼 입력되는 일반 제품이면 됩니다.
- 대출용 태블릿 또는 PC 1대 (브라우저만 있으면 됨)
- 책에 붙일 바코드 — 책 뒤의 ISBN 바코드를 그대로 쓰거나, **바코드 생성** 메뉴에서 자체 바코드를 인쇄해 붙입니다. 보드게임·교구처럼 ISBN이 없는 물건도 자체 바코드로 등록해 빌려줄 수 있어요.

### 1. 사이트 유형에서 '학원' 선택

**관리 → 사이트 유형**에서 학원을 고르면 학원에 맞는 설정이 한 번에 적용됩니다: QR 회원카드 로그인, 관리자만 회원 생성, 홈 화면 리더기 대출 OFF, 대출 기간 7일, AR 정보 사용, 원서 ISBN 보충 조회(Open Library) 사용. 고른 뒤에도 각 설정 화면에서 하나씩 바꿀 수 있습니다.

학생 등록·QR 회원카드 발급·카드 인쇄는 [유치원 모드](#kids-member)와 같습니다(반 + 이름). 학원에서는 학년과 레벨 범위(ZPD)도 함께 적을 수 있습니다.

### 2. 원서·AR 레벨 설정

**관리 → 원서·AR 레벨**에서 두 기능을 켜고 끕니다. 둘 다 사이트 유형과 별개라 아파트·학교 도서관에서도 쓸 수 있습니다.

- **AR 레벨 정보 사용** — 도서 등록·수정 화면에 AR 칸이 생기고, 학생 도서 검색에서 레벨로 찾고 레벨순으로 볼 수 있습니다. 꺼도 입력해 둔 AR 정보는 지워지지 않고 화면에서만 숨겨집니다.
- **Open Library 보충 조회** — 바코드(ISBN)로 책을 찾을 때 카카오 도서 검색에 없는 원서는 Open Library(해외 도서 정보)에서 제목·저자·출판사·표지를 가져옵니다.

<img src="docs/images/academy/academy-ar-settings.png" width="800" alt="원서·AR 레벨 설정" />

### 3. 책마다 AR 정보 (Book Level · Points · Quiz No · Interest)

도서 등록·수정 화면에 **AR 정보** 칸(Book Level, Points, Quiz No, Interest, 단어 수, Lexile)이 생깁니다. **AR 찾기**를 누르면 책 제목이 복사되고 AR BookFinder가 열려서 값을 확인해 옮겨 적을 수 있습니다. 도서 상세에는 `BL 4.4 · 5.0 pts · Quiz #…` 배지로 보입니다.

> **AR 정보는 자동으로 가져오지 않습니다.** AR 정보를 관리하는 Renaissance는 공개 API를 제공하지 않습니다. 그래서 학원이 이미 가진 AR 목록(엑셀)을 [일괄 등록](#academy-import)으로 붙여 넣거나, AR BookFinder에서 확인해 직접 입력합니다.

### 4. 엑셀(CSV) 일괄 등록 — 도서 · AR 정보 · 학생

**일괄 등록**에서 원서 목록, 이미 등록한 책의 AR 정보, 학생 명단을 한꺼번에 넣습니다. 엑셀에서 머리글 줄부터 표를 복사해 붙여 넣거나 CSV 파일을 고르고 **미리보기**를 누르면 줄마다 결과가 나옵니다(OK / 이미 있는 책 / 없는 책장 등).

- ISBN만 있어도 책 정보(제목·저자·출판사·표지)를 찾아 빈 칸을 채웁니다. 엑셀에 적은 값이 먼저입니다.
- '이미 있는 책은 건너뛰기'를 켜 두면 같은 파일을 두 번 올려도 복본이 생기지 않습니다.
- 엑셀 파일(.xlsx)은 바로 읽지 못하므로 파일로 올릴 때는 CSV로 저장해 주세요.

### 5. AR 정보 없는 책 입력표

**AR 정보 입력**은 AR 레벨이 비어 있는 책만 모아 표로 보여 줍니다. 칸 사이는 Tab, 아래 줄 같은 칸은 Enter로 옮겨 가며 빠르게 입력하고 **한 번에 저장**합니다. 같은 ISBN의 복본은 한 줄로 묶여 함께 저장됩니다.

<a id="academy-classes"></a>

### 6. 반별 현황 — 대출 · 연체 · AR 통과

**반별 현황**에서 반마다 학생 수·대출·연체 권수를 보고, 반을 누르면 학생별 학년, 레벨(ZPD), 빌린 책과 반납 예정일(연체는 빨간색), 최근 30일 동안 반납한 책과 AR 통과 여부가 나옵니다. 여기서 바로 **AR 통과**를 체크할 수 있습니다.

학생을 골라 **반 이동**이나 **퇴원** 처리를 하고, **반 이름 변경**을 하면 그 반 학생들의 반도 함께 바뀝니다. 퇴원한 학생은 대출·카드 인쇄·랭킹에서 빠집니다.

<img src="docs/images/academy/academy-classes.png" width="800" alt="반별 현황 (대출·연체·AR 통과)" />

<a id="academy-return"></a>

### 7. 반납할 때 AR 퀴즈 통과 체크

**AR 퀴즈는 학생이 Renaissance(AR 프로그램)에서 풉니다.** 책빌리지는 퀴즈를 내거나 채점하지 않고, 선생님이 확인한 **통과 기록만** 남깁니다.

반납 화면에서 책 바코드를 찍으면 반납 완료 아래에 **AR 퀴즈** 상자가 나옵니다. **AR 퀴즈 통과 체크**를 누르면 그 책의 포인트와 단어 수가 학생 기록에 쌓입니다. 잘못 눌렀으면 취소할 수 있고, 젤리 포인트와는 연결되지 않습니다.

<img src="docs/images/academy/academy-return-ar.png" width="800" alt="반납 화면의 AR 퀴즈 통과 체크" />

<a id="academy-ranking"></a>

### 8. AR 포인트 랭킹

**랭킹 → AR 포인트** 탭에서 기간·반별로 통과 권수, 읽은 단어 수, 포인트 순위를 봅니다. 선생님이 통과를 체크한 날(한국 시간) 기준이며 퇴원생은 빠집니다.

<img src="docs/images/academy/academy-ranking-ar.png" width="800" alt="랭킹 AR 포인트 탭" />

### 9. 학생 상세 — 학년 · 레벨 · AR 통과 기록

회원 상세의 **학원 정보**에서 학년, 레벨 범위(ZPD), 재원/퇴원 상태를 고치고 통과 권수·누적 포인트·읽은 단어 수와 통과한 책 목록(체크한 선생님 포함)을 봅니다. **책 찾아서 통과 기록**으로 대출 기록이 없는 책(교실에서 읽은 책 등)도 찾아서 통과를 기록할 수 있습니다.

### 10. 레벨 라벨 인쇄

**레벨 라벨 인쇄**에서 책장과 레벨 범위를 골라 책등에 붙일 AR 레벨 라벨을 만듭니다. 라벨 하나는 23.5×36mm, A4 한 장에 56개(8개 × 7줄)이고 레벨대마다 색 띠가 달라 책장에서 레벨을 한눈에 볼 수 있습니다. 라벨 아래 칸(제목/바코드/없음)과 앞에서 비울 칸(쓰다 남은 라벨지 이어 쓰기)을 고를 수 있습니다.

<a id="academy-need"></a>

### 필요한 것

- **2D(QR) 바코드 리더기** — 학생이 QR 회원카드로 로그인합니다. 유치원 모드와 같은 일반 USB 리더기면 됩니다.
- **AR 정보 목록** — 학원이 가진 원서 AR 목록(엑셀)이나 AR BookFinder에서 확인한 값. 공개 API가 없어 자동으로 채워지지 않습니다.
- **AR 퀴즈 이용** — 퀴즈는 Renaissance에서 풉니다. 학원이 따로 이용 중이어야 하고, 책빌리지는 통과 기록만 합니다.
- 원서 바코드 — 책 뒤 ISBN 바코드를 그대로 쓰거나 **바코드 생성** 메뉴의 자체 바코드를 붙입니다. 레벨 라벨은 A4 용지에 인쇄해 잘라 붙이면 됩니다.

<sub>AR, Accelerated Reader, ATOS는 Renaissance Learning의 상표입니다. 책빌리지는 Renaissance와 관계가 없습니다.</sub>

## 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend / Backend | Next.js 16 (App Router, TypeScript) |
| Database / Auth | Supabase (PostgreSQL, 15 테이블 + 2 뷰) |
| UI | shadcn/ui + Tailwind CSS 4 (Yellow 테마) |
| Deployment | Vercel (서울 리전) |
| External API | 카카오 도서 검색 API, Open Library (원서 보충 조회, 선택) |
| Barcode | html5-qrcode |

## 시작하기

```bash
git clone https://github.com/dean-studio/bookvillage_app.git
cd bookvillage
npm install
cp .env.example .env.local  # 환경변수 설정
npm run dev                  # http://localhost:6100
```

### 환경변수

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
```

### 데이터베이스

```bash
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase db push
```
