# 책빌리지 (Book Village) — 작은도서관 도서 대여 관리 프로그램

## Versions

### v0.5

- **비회원(게스트) 대출** — 앱 가입 없이 종이에 적고 가는 이용자를 동/호수·이름·전화번호로 등록해 대여. `101-211` 입력 시 `101동 211호` 자동 변환, 도서 제목 검색으로 여러 권 한 번에 처리, 대출일 지정 가능. 게스트는 젤리 미지급·권수/연체 제한 없음. 대여중/연체/반납 목록에 '게스트' 배지 표시, 대출 정보(이름·동호수·대출일) 사후 수정 가능
- **공지사항** — 관리자 공지 작성/이미지 첨부/관리, 주민 접속 시 팝업 노출 + 내 서재·하단 네비 미읽음 배지 + 목록 열람
- **주민 대여 취소** — 대여 당일에 한해 주민이 직접 취소 (지급된 대출 젤리 자동 회수)
- **제목으로 대여** — 대여하기 화면에서 바코드 없이 도서명으로 검색해 셀프 대여, 최근 검색어 저장, 동일 제목 여러 권일 때 바코드 유형 선택
- **제목 검색 반납** — 반납 페이지에서 바코드 없이 도서명/대여자로 검색해 반납
- **반납 내역 개선** — 기간·검색 필터, 페이지네이션, 처리자 표시
- **관리자 독서록 열람** — 전체 독서록 목록/검색/페이지네이션
- **주민 PIN 재설정** — 관리자가 주민 상세에서 비밀번호(PIN 4자리) 초기화
- **회원가입 비밀번호 재확인** — PIN 재입력 단계 추가(색상 구분), 불일치 시 즉시 재입력
- **도서 정보 수정** — 관리자 도서 상세에서 제목·저자·출판사·서가 위치·표지 직접 수정
- **실제 ISBN 직접 입력 등록** — 카카오 검색이 안 되는 도서를 ISBN 직접 입력으로 등록(중복 자동 검사)
- **바코드 스캔 한글 IME 복원** — 리더기가 한글 입력 상태로 `BV`를 `ㅠㅍ`처럼 찍는 문제 자동 복원
- **가나다순 자연 정렬** — 도서 목록 제목순 정렬 시 `전천당 1, 2, …, 10` 순서 유지
- **자체 바코드 대량 인쇄** — 한 번에 최대 1,000장 생성·인쇄
- **로고 인쇄** — 도서관 로고 스티커 인쇄 페이지
- **홈 화면 추가(PWA)** — manifest·앱 아이콘 적용으로 스마트폰 홈 화면에 앱처럼 설치
- **대시보드 카드 클릭 이동** — 통계 카드 클릭 시 해당 목록으로 바로 이동
- **도서 상세 서가 미니맵** — 위치 서가를 확대·강조(펄스 애니메이션)해 찾기 쉽게 표시
- **검색 상태 유지** — 도서 검색 후 뒤로가기 시 검색어·결과 보존
- **무인 도서관 이용 안내문** — 인쇄용 A4 가이드(앱 안내 / 수기 대여 / 최대 5권 등)

- 등록/대출 처리자(담당 사서) 기록 + 관리자 이름 표시
- 서가 그리드 개선 — 서재 리사이징, 분류별 색상 구분, 이름 줄바꿈

### v0.3

- 주민 로그인 방식 개선 — 휴대폰 번호 없이 **동 → 호수 → 비밀번호**로 로그인 (같은 세대 여러 명도 비밀번호로 구분)
- 회원가입 호수 입력 4자리 지원 (예: 1104호)
- 바코드 스캔 인식 개선 — 부가기호(가격기호)가 붙은 **한국 도서 EAN-13 바코드** 인식 (전체 스캐너에 인식 포맷 명시 + 스캔 영역 최적화)
- 브랜딩 커스터마이징 — 도서관 이름 기반 페이지 제목, OG 이미지·파비콘 적용 (SNS 공유 미리보기 지원)

### v0.2

- 카카오톡 채널 연동 (관리자 설정 > 채널 ID 입력 → 로그인/내 서재에 상담 버튼)
- 회원가입 확인 단계 추가 (입력 정보 요약 → 확인 후 최종 가입)

- 중복 도서 등록: 이미 등록된 ISBN 도서를 자체 바코드로 추가 등록
- 바코드 스캔 전체 화면 (프레임 제거, 카메라 영역 확대)
- 스캔 중 카메라 라이트(토치) ON/OFF 지원
- 연속 스캔 중 중복 바코드 감지 시 토스트 경고 + 스캔 유지
- 소프트 삭제 도서 재등록 시 자동 복원 (바코드 충돌 해결)

## 소개 
> 관리비 0원으로 운영하는 작은도서관 도서 대출/반납 관리 시스템

아파트, 학교, 마을 작은도서관을 위한 **무료 오픈소스 도서관 관리 프로그램**입니다. 바코드 스캔으로 도서 대여/반납, 도서 검색, 연체 관리, 독서 퀴즈, 독서록까지 — 스마트폰 하나로 도서관을 운영할 수 있습니다.


## 왜 만들었나요?

> *"관리할 사람이 없어서 닫히는 도서관이 하나라도 줄었으면 합니다."*

아이를 키우면서 동네 작은도서관을 자주 찾습니다. 그런데 사람이 없어 문을 닫거나, 운영을 포기하는 곳이 점점 늘어나고 있었습니다.

수기 장부, 엑셀 대장, 수작업 연체 관리... **아날로그 방식의 도서관 운영은 자원봉사자에게 너무 큰 부담**입니다. 결국 지치고, 포기하게 됩니다.

하지만 **아이들에게 도서관은 특별한 공간**입니다. 책을 직접 만지고, 고르고, 읽는 경험은 어떤 디지털 콘텐츠로도 대체할 수 없습니다. 이 공간이 사라지는 건 너무 아까운 일이었습니다.

그래서 직접 만들었습니다.

- **스마트폰 하나면 충분합니다** — 누구나 사서가 될 수 있고, 주민은 셀프 대여까지 가능합니다
- **관리비 0원** — Vercel + Supabase 무료 플랜으로 운영비가 들지 않습니다
- **아이들이 즐거워합니다** — 독서 퀴즈를 풀고, 독서록을 쓰고, 젤리 포인트를 모으며 "오늘 젤리 몇 개 모았어!" 하고 좋아합니다

## 주요 기능

### 주민
- **셀프 대여** — 바코드 스캔으로 직접 대출 (별도 앱 설치 불필요)
- **도서 검색** — 제목/저자 검색 + SVG 서가 위치 맵
- **내 서재** — 대여 현황, 반납 이력, 알림, 젤리 잔액
- **독서 퀴즈** — 책 반납 후 퀴즈 풀기 (+3 젤리)
- **독서록** — 별점 + 감상문 작성 (+10 젤리)
- **젤리 포인트** — 대출/반납/독서록/퀴즈 활동 시 자동 지급
- **알림** — 반납 D-3, 당일, 연체 알림 + 미읽은 배지
- **추천 도서** — "이 책을 본 사람이 본 도서"

### 관리자
- **도서 등록** — 바코드 스캔 → 카카오 API 자동 완성 → SVG 서가 배치
- **대출/반납 처리** — 바코드 스캔 + 서가 위치 안내 팝업
- **반납 내역** — 처리자 기록, 연체 여부 표시
- **주민 관리** — 목록, 상세, 젤리 수동 지급/차감
- **랭킹** — 기간별 다독왕/인기도서/독서록/젤리 순위
- **통계 대시보드** — 대출/반납/가입 통계, 연체 현황, 신작
- **연체 관리** — 알림 발송 + 대출 자동 제한
- **설정** — 대출 권수, 기간, 젤리 지급량, 퀴즈, 관리자 승인

## 기술 스택

| 영역 | 기술 |
|------|------|
| Frontend / Backend | Next.js 16 (App Router, TypeScript) |
| Database / Auth | Supabase (PostgreSQL, 15 테이블 + 2 뷰) |
| UI | shadcn/ui + Tailwind CSS 4 (Yellow 테마) |
| Deployment | Vercel (서울 리전) |
| External API | 카카오 도서 검색 API |
| Barcode | html5-qrcode |

## 시작하기

```bash
git clone https://github.com/dean-studio/bookvillage_app.git
cd bookvillage
npm install
cp .env.example .env.local  # 환경변수 설정
npm run dev                  # http://localhost:6100
```

### 환경변수

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
KAKAO_REST_API_KEY=your_kakao_rest_api_key
```

### 데이터베이스

```bash
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase db push
```
